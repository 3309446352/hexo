## **一、四国当前政治格局一览**


### **🇬🇧 英国**


| 项目        | 详情                                        |
| --------- | ----------------------------------------- |
| **执政党**   | 工党（Labour Party）— **中左翼**                 |
| **首相**    | 基尔·斯塔默（Keir Starmer），2024年7月上台            |
| **现状**    | ⚠️ **执政危机**                               |
| 支持率       | 仅**27%**，65%不支持                           |
| **最大反对党** | 改革党（Reform UK）— **极右翼民粹**                 |

英国**两党制正在崩塌**。百年以来，政权始终在保守党与工党之间轮替。但2026年5月的地方选举打破了这个格局——法拉奇领导的改革党以1,453席超越工党（1,063席）和保守党（801席）。BBC民调显示若立即大选，改革党支持率26%，工党与保守党双双跌至17%。[1](https://app.lobehub.com/agent/agt_TrkVT7VGqHL3/tpc_ELBCWn92da0N#user-content-fn-1)

## **四、全球风向：四个核心趋势**


### **趋势一：极右翼从"搅局者"变为"准执政者"**


2026年5月《光明日报》的深度分析指出[2](https://app.lobehub.com/agent/agt_TrkVT7VGqHL3/tpc_ELBCWn92da0N#user-content-fn-2)：

> 极右翼崛起甚至全面扩张，从处于边缘位置的"搅局者"转变为处于核心位置的"准执政者"。
- 英国改革党：地方议会第一大党
- 德国选择党：全国支持率第一（28%）
- 法国国民联盟：2027总统大选领跑（37%）

### **趋势二：战后欧洲社会市场经济模式系统性崩塌**


这是极右翼崛起的**深层经济根源**[2](https://app.lobehub.com/agent/agt_TrkVT7VGqHL3/tpc_ELBCWn92da0N#user-content-fn-2)：

- 欧盟制造业占GDP比重：从1980年代的~30% → 2024年**14.3%**
- 德国社会福利支出：**31.2%**（历史峰值），养老金缺口每年1,210亿欧元
- 法国公共债务：**115.6%**（2025），2026年预计117.9%
- 北约防务开支目标提至GDP的**5%**，欧盟每年需额外筹措近万亿欧元
- 欧元区2026年增速放缓至**0.9%**，通胀跃升至**3.0%**

底层逻辑：**高税收不再换来高保障**→民众对传统政党的"社会契约"丧失信心→极右翼以反建制、反移民叙事收割民意。


### **趋势三：政治碎片化——两党制正在消亡**


英国百年两党制在2026年5月出现了结构性崩塌。英国改革党成为**百年以来首个全国支持的第三党**。德国联盟党+社民党合计支持率跌破50%。法国传统左右两党（社会党、共和党）早在2022年就沦为边缘角色。[1](https://app.lobehub.com/agent/agt_TrkVT7VGqHL3/tpc_ELBCWn92da0N#user-content-fn-1)


这不再是"钟摆效应"（左/右交替），而是**"碎片化重组"**——选民不再在左和右之间摇摆，而是抛弃了整个传统政党体系。


### **趋势四：极右翼可能正在触顶**


但有一个重要的反信号。2026年的多篇文章指出[3](https://app.lobehub.com/agent/agt_TrkVT7VGqHL3/tpc_ELBCWn92da0N#user-content-fn-3)[4](https://app.lobehub.com/agent/agt_TrkVT7VGqHL3/tpc_ELBCWn92da0N#user-content-fn-4)：

- 匈牙利欧尔班在2026年下台——这是欧洲极右翼的一次重大挫败
- 特朗普对欧洲极右翼来说正在成为"有毒资产"（El País, 2026年4月）
- 部分国家选民开始对极右翼的实际执政能力产生疑虑

皮尤研究中心2026年5月的十年回顾报告指出[3](https://app.lobehub.com/agent/agt_TrkVT7VGqHL3/tpc_ELBCWn92da0N#user-content-fn-3)：右翼民粹主义在脱欧后的十年间大幅扩张，但**是否已经达到顶点，尚不确定**。

## **五、对中国的影响**


### **直接影响**


| 影响维度      | 分析                                                             |
| --------- | -------------------------------------------------------------- |
| **贸易与关税** | 特朗普政府对华关税政策持续施压；欧洲极右翼普遍倾向**贸易保护主义**（"保护本土产业""再工业化"），中欧贸易摩擦可能加剧 |
| **技术脱钩**  | 美国对华技术封锁大概率持续；欧洲在压力下可能选择性跟进                                    |
| **投资审查**  | 欧洲对中国投资的审查可能进一步收紧，极右翼主张"经济主权"                                  |
| **产业链重组** | 欧美推动"去风险化"（de-risking），供应链向友岸外包趋势不变                            |


### **结构性机遇**


| 机遇           | 分析                                    |
| ------------ | ------------------------------------- |
| **欧洲内部分裂**   | 政治碎片化意味着欧洲难以形成统一的对华政策——各国各自为政，中国可分化应对 |
| **美国孤立主义**   | 特朗普"美国优先"疏远传统盟友，为中国在欧洲和亚太拓展外交空间留下真空   |
| **"全球南方"窗口** | 欧美内顾之际，中国在金砖、上合等框架下加强对新兴市场的影响力        |
| **经济吸引力**    | 欧洲经济困境使其对中国市场和投资的依赖加深，"脱钩"成本更高        |
| **多极化加速**    | 西方阵营的内部分裂客观上加速了世界多极化，与中国的外交战略方向一致     |


### **战略风险**

> **最大的风险不是极右翼本身，而是整个西方治理体系的动荡和不可预测性。** 当主要国家政府支持率普遍跌至20%以下时，外交政策可能随时因选举结果而翻转。对中国而言，这意味着：没有稳定的"对手"可以打交道，每一个四年都可能面临政策从头来过。

## **六、一句话总结**


**2026年的全球政治风向是：中左/中间派在台上执政但摇摇欲坠，极右翼在台下崛起但尚未全面掌权。** 世界处于一个高度不稳定的"中间状态"——旧秩序正在崩塌，新秩序尚未成形。对中国而言，这既是战略压力加剧的时期，也是多极化格局加速形成的窗口期。
